## How to use these guides

- Each guide has: goal, what to learn, resources (with options), practical projects, agent exercises, mentor drills, a "done when" checklist, and pitfalls.
- **Resources are all free.** Where there are options, they are labeled A / B / C. Pick one per topic; do not do all of them.
- Resource types: 📖 reading, 🎥 video, 🛠 hands-on, 📚 book/course.
- **Depth levels:** *Own* means deep expertise. *Literacy* means know the concepts and be able to direct an agent. Do not go deeper than the label says.
- **Rule for everything:** if an agent can do it well enough, she does not learn to do it by hand. She learns to direct it and check the result.

## Notes

- Links were checked when the guides were written, but sites move. If a link is dead, search the title.
- Tool names and Claude Code features change often. Prefer the official docs over older tutorials.
- Use only tools that are approved at work (Claude, open-source IDEs and orchestrators, allowlisted MCPs, CLIs).
- Test apps and sample data are public demo targets. Never put real customer data into prompts.
